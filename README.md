## SQL - Coopérative Agricole (Côte d'Ivoire)

##  Description

Ce projet simule la gestion d'une coopérative agricole en Côte d'Ivoire.

La base de données permet de gérer :

- Les producteurs
- Les parcelles
- Les cultures
- Les récoltes

L'objectif de ce projet est de pratiquer SQL à travers un cas concret inspiré du secteur agricole ivoirien.

##  Technologies

- SQLite
- SQL

##  Structure de la base de données

La base de données est composée de 4 tables relationnelles :

- `producteurs`
- `parcelles`
- `cultures`
- `recoltes`

Les tables sont reliées entre elles grâce aux clés primaires (PK) et clés étrangères (FK).

##  Analyses réalisées

Quelques questions business étudiées dans ce projet :

- Quels sont les producteurs présents dans la base ?
- Quelle région produit le plus de maïs ?
- Quels producteurs cultivent l'arachide ?
- Quelle est la quantité moyenne récoltée ?
- Quelle culture génère le plus de chiffre d'affaires potentiel ?
- Quelles récoltes ont été réalisées en mars 2025 ?
